# Douyin Keyword Batch Downloader

基于 `Evil0ctal/Douyin_TikTok_Download_API` 二次开发的抖音关键词批量采集与下载工具。

本项目新增了一个本地网页工作流，可以使用自己的抖音账号登录，按关键词搜索视频，自动滚动采集视频 URL，并批量下载 `.mp4` 文件。

## 主要功能

- 使用真实浏览器登录自己的抖音账号
- 按关键词搜索，例如 `vlog`
- 自动滚动搜索结果页
- 自动采集并去重视频 URL
- 复用原项目解析逻辑获取真实视频资源地址
- 批量下载 `.mp4` 文件
- 支持下载并发数配置
- 支持失败重试和 `.part` 临时文件，避免半截文件污染结果

## 安装依赖

建议使用 Python 3.10 或更高版本。

```bash
pip install -r requirements.txt
playwright install chromium
```

如果本机已安装 Microsoft Edge，项目会优先尝试使用 Edge 浏览器。

## 启动服务

```bash
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

启动后打开：

```text
http://127.0.0.1:8000/api/batch
```

API 文档地址：

```text
http://127.0.0.1:8000/docs
```

## 使用方法

1. 打开批量下载页面。
2. 点击“打开登录窗口”。
3. 在弹出的浏览器里登录自己的抖音账号。
4. 回到批量页面，填写关键词、最大视频数、滚动次数、滚动间隔和下载并发数。
5. 点击“开始采集并下载 mp4”。
6. 页面会展示采集到的 URL、下载进度、成功文件和失败原因。

下载文件默认保存到：

```text
download/batch_douyin
```

浏览器登录状态保存在：

```text
.batch_browser_profile
```

该目录可能包含账号 Cookie，不要提交或分享。

## 主要技术路线

本项目没有采用纯 HTTP 请求直接抓取的方式，而是采用“真实浏览器登录 + 页面自动化采集 + 后端解析下载”的路线。

整体流程：

1. 使用 Playwright 启动持久化浏览器上下文。
2. 用户在真实抖音网页中完成登录。
3. 后端复用浏览器 Cookie 和登录状态。
4. 后端打开抖音关键词搜索页。
5. 自动滚动页面，触发搜索结果动态加载。
6. 从页面 DOM、链接和 `modal_id` 中提取视频 ID。
7. 将采集结果统一规范化为标准视频 URL。
8. 调用原项目 `HybridCrawler` 解析真实视频资源地址。
9. 使用异步下载器并发下载 `.mp4` 文件。
10. 对失败下载进行重试，并使用 `.part` 临时文件保证结果完整性。

## 大规模任务建议

当前版本适合验证链路和中小规模批量下载。

如果需要万级视频量，建议进一步扩展：

- 先采集 URL，再分批下载
- 使用 SQLite 保存 URL 队列和下载状态
- 支持服务重启后的断点续跑
- 记录失败原因并支持单独重试失败任务
- 按关键词、批次、时间管理任务
- 增加成功率、失败率、下载速度等统计报表

## 注意事项

- 请使用自己的账号登录。
- 不建议将下载并发数设置过高，建议从 `4` 到 `8` 开始测试。
- 抖音视频源可能存在限速、断流、风控等情况，下载失败时可降低并发或稍后重试。
- 本项目仅用于学习和技术研究，请遵守相关平台规则和法律法规。
